# JavaScript, Fall 2026: Class Examples

The code we wrote together in class, in the order we went through it. **Demo** runs the example in your browser; **code** shows the files.

Many scripts contain several versions of the same example, one after the other. Earlier steps are commented out (`//`): to try one, comment out the active code and uncomment the step you want. Examples marked *console only* print to the browser console (right-click → Inspect → Console).

To download everything, click the green **Code** button on GitHub and choose **Download ZIP**.
